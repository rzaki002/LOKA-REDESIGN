# 🌿 Loka Studio - Creative Independent Studio Landing Page

> Website landing page modern dan estetis untuk **lokastudio**, sebuah studio kreatif independen yang berfokus pada strategi, identitas, dan pengalaman digital bagi brand yang ingin tumbuh dengan cara berbeda.

## ✨ Fitur Utama
- **Navbar Interaktif:** Dilengkapi menu navigasi (Tentang, Layanan, Karya, Kontak) serta tombol *Call to Action* "Mulai proyek".
- **Hero Section yang Kuat:** Menampilkan *tagline* utama *"Brand baik punya cerita"* dengan tata letak minimalis dan elegan.
- **Visual & Badge Unik:** Desain kartu gambar melengkung yang elegan serta lencana aksen *"Made with intention"*.
- **Social Proof / Partner:** Bagian informasi kolaborasi dengan indikator partner tumbuh untuk memperkuat kredibilitas *brand*.
- **Responsive Design:** Tampilan fleksibel yang nyaman diakses melalui perangkat desktop maupun *mobile*.

## 🛠️ Teknologi yang Digunakan
- **Frontend:** React.js
- **Styling:** Tailwind CSS
- **Tools:** Vite, VS Code, Git & GitHub
